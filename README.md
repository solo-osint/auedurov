# SHADOWGRAPH 5.2 для GitHub Pages

Полностью статический сайт с интро и локальными зашифрованными профилями. Серверной части и переходов на хост ChatGPT нет.

Сайт опубликован на https://solo-osint.github.io/auedurov/. Для публикации выберите Settings → Pages → Deploy from a branch, ветку `main` и папку `/(root)`.

Вкладка «Регистрация» создаёт локальный профиль и случайный ключ. Можно указать ранее выданный SG1/SGM. Сохраните ключ: без него зашифрованные проекты не восстановить. После обновления страницы нужно войти по ключу снова. Ключи и материалы ни на какой сервер не отправляются.

Профили, занятость ников и данные отдельные на каждом устройстве и в каждом браузере. Централизованных приглашений, глобальных ролей владельца/участника, проверки никнеймов между устройствами и входа через Google/Telegram/GitHub в этой версии нет. Любой посетитель может создать свой локальный профиль; чужие зашифрованные проекты его ключ не открывает.

Для переноса со старого адреса экспортируйте проекты в JSON на старом сайте и импортируйте здесь. Прежняя серверная зашифрованная резервная копия использует другой ключ хранилища и напрямую не подходит к локальному профилю. Старое хранилище не изменяется. Экспортированные JSON/PDF не зашифрованы; храните их отдельно.

## Анализ 5.1

Полные адреса сравниваются по городу, типу и названию улицы, дому, корпусу, строению, литере, квартире и другим указанным компонентам. Разные сокращения нормализуются. Точные совпадения из разных файлов используют один узел со всеми источниками. Неполные адреса, опечатки и отличающиеся компоненты не объединяются автоматически. Проверка локальная: существование адреса и его принадлежность человеку не подтверждаются. Наиболее полно поддерживаются русскоязычные адреса с обозначением типа улицы.

В меню «Инструменты» добавлены «Проверка адресов» и «Совпадения источников». Объединение существующих дублей требует просмотра и подтверждения; отмена доступна в истории. Копии файлов с тем же содержимым не являются независимым подтверждением. Одинаковые имена людей в разных записях больше не объединяются автоматически. Адрес можно собрать из отдельных полей JSON, CSV и строк TXT: город, улица, дом, квартира.

Для старого проекта используйте «Повторить анализ», затем «Инструменты → Проверка адресов». Прежние узлы и ручные правки сохраняются, поэтому старые дубли нужно просмотреть вручную. Перед обновлением сохраните резервный экспорт проектов.

## Версия 5.2 — объяснения, анализ и фотографии

На каждой карточке есть «?». Для объекта открываются правила распознавания, фрагменты, источники и причины связей; для фото — метаданные. При выборе обычного блока или линии в боковой панели есть «? Правило, источник и причина». Старым связям новые объяснения добавит «Повторить анализ». Для ручных связей отсутствующее правило не выдумывается. Автоматические связи означают совместное упоминание, не доказанное отношение.

В меню «Инструменты»:
- **История контактов**: сведения об адресах, телефонах, email и аккаунтах со статусами, датами из текста и отдельными датами загрузки. Смена контакта автоматически не предполагается.
- **Сопоставление людей**: кандидаты по имени с контактом, контакту с датой рождения или телефону вместе с email. Сначала показываются признаки, затем предпросмотр и подтверждение. Несовпадающие даты рождения блокируют предложение. Общий контакт может принадлежать семье или организации — проверяйте вручную.
- **Сравнить расследования**: точные совпадения внутри своего профиля. Можно выбрать, какие совпадения перенести; копируются исходные файлы целиком и относящиеся к выбранным совпадениям доказательства. Полный перенос других сущностей не производится. Имя человека само по себе не используется. Действие доступно для отмены в истории.
- **ГАР / ФИАС**: подключение локального JSON/CSV-индекса. Официальная база не включена, автоматического онлайн-запроса нет. Проверяется наличие точной записи в загруженной версии. Отсутствие совпадения не доказывает отсутствие адреса. Происхождение импортированного пользователем индекса не удостоверяется.

Отрицания «не проживает», «номер больше не используется» и прежние сведения выделяются в объяснениях и истории. Это разбор по правилам, который может ошибаться на сложных предложениях, иронии или отрицании с несколькими объектами. Это не полноценное понимание текста. Подтверждайте важные факты по источнику.

### Фото
Добавляйте JPG/JPEG, PNG, WebP или GIF обычной кнопкой добавления файлов; нажмите «?» на фото. Выводятся все извлечённые поддерживаемым парсером теги в двух представлениях: расшифрованном и исходном. Запрошены EXIF/TIFF, GPS, IFD0/IFD1, Interop, XMP, IPTC, ICC, JFIF, PNG IHDR, UserComment, MakerNote (закрытые данные могут оставаться байтами). Для JPEG/PNG/WebP дополнительно выводится список контейнерных блоков; сырые блоки метаданных приложены в base64. Поиск строк и скачивание полного JSON работают без отправки файла на сервер. Оригинал тоже доступен для скачивания. Применяется прежний лимит 12 МБ на файл.

«Все доступные» не означает восстановление удалённых тегов или расшифровку любого фирменного формата. Некоторые форматы и теги не поддерживаются. Парсер сообщает ошибки, а оригинал сохраняется целиком. Число строк определяется реальным содержимым, искусственно строки не добавляются. Координаты и даты в метаданных могут быть подделаны. JSON метаданных скачивается без шифрования.

### Подготовка индекса ГАР
Официальный портал и выгрузки: https://fias.nalog.ru/ и https://fias-file.nalog.ru/Frontend.

Для собственного индекса JSON используйте массив объектов вида `{"address":"г. Москва, ул. Ленина, д. 10","fias_id":"ID из ГАР","date":"дата версии","source":"название выгрузки"}`. CSV использует такие же заголовки. До 50 000 записей / 20 МБ на проект. Имена адресов должны включать полный город, тип улицы и дом. Все указанные компоненты сопоставляются строго, поэтому отсутствие корпуса, региона или квартиры в одной из записей может потребовать отдельной проверки.

В архив включён Node.js-конвертер `convert-gar.cjs`. Для распакованной региональной XML-выгрузки запустите `node convert-gar.cjs "папка-региона" "index.json"`. В папке нужны AS_ADDR_OBJ, AS_ADM_HIERARCHY, AS_HOUSES; для дополнительных номеров — AS_ADDHOUSE_TYPES. Используйте одну согласованную полную версию, а не смесь обновлений. Конвертер читает активные актуальные объекты и адреса типа «дом» с городом и улицей; сельские/нестандартные адреса, другие типы зданий и квартиры не входят. Это ограниченный конвертер, а не полная реализация модели ГАР. Для большого региона подготовьте отдельный индекс района с лимитами выше; конвертеру требуется память под иерархию региона. Не публикуйте индекс с материалами расследований в публичном репозитории.

Обновление: сохраните резервный экспорт, замените содержимое сайта, откройте по прежнему адресу, войдите своим локальным ключом и повторите анализ нужных файлов. Никакие новые ключи или проекты в поставку не входят.
