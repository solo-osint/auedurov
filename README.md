# SHADOWGRAPH 5.9 — GitHub Pages

Готовый статический сайт с интро, локальными зашифрованными профилями и графом расследования. Серверная часть и вход через ChatGPT не используются.

## Установка

1. Перед обновлением сохраните резервный экспорт своих проектов.
2. Загрузите содержимое архива в корень репозитория, сохраняя папку `public`.
3. GitHub Pages публикует ветку `main` из `/(root)`.
4. Сайт: https://solo-osint.github.io/auedurov/. При обновлении используйте прежний адрес: локальные данные привязаны к адресу сайта и браузеру.

Регистрация создаёт локальный профиль и случайный ключ. Можно указать ранее выданный ключ SG1/SGM. Сохраните ключ отдельно: без него проекты не восстановить. После перезагрузки страницы нужно войти по ключу заново. Метаданные профилей и занятость ников отдельные в каждом браузере/на устройстве; централизованных аккаунтов, глобальных ролей и входа через Google/Telegram/GitHub нет. Материалы не отправляются на сервер приложения. Экспортированные JSON, PDF и метаданные фото не зашифрованы.

## Новое в этой версии

- Завершено исправление больших графов: рабочий масштаб вместо тысячи микрокарточек, чистый общий план без веера связей файлов, локальные маршруты в фоне. «Общий план» показывает всё; приблизьте область для работы. «Линии: читаемый вид» позволяет явно включить все линии. Позиции, объекты и связи не удаляются. На плотных участках часть маршрутов может оставаться упрощённой.
- «Вид: карточки / Вид: круги» переключает обычные блоки и сетевой граф с круглыми узлами. Положение кругов хранится отдельно. Работают выбор, перемещение, поиск Enter, фильтры, связи, статусы и объяснения. В сетевом виде «Авторасстановка» пересчитывает круги в отдельном потоке. На большом отдалении подписи и линии упрощаются. Сеть одновременно рисует до 2000 линий, карточки — до 2500 в режиме всех линий; данные остаются полными.
- Интерфейс стал темнее. Выбранный пользователем фон проекта сохранён. В инспекторе доступны цвет заливки отдельного блока, палитра и изменение заливки всех блоков. Цвет контура и цвет связей редактируются отдельно.
- Новая эмблема установлена в интерфейс и favicon. «Инструменты → Аватар SHADOWGRAPH» скачивает PNG/SVG. Файлы доступны также в public/brand.
- PDF получил тёмную обложку, обзор статусов, отдельную страницу графа, реестр источников S, карточки объектов N и связи R с объяснениями. Изображение учитывает режим и фильтры; реестры содержат весь проект. Большая схема на печатной странице будет мелкой — для деталей используйте интерактивный проект.
- Анализ понимает дополнительные названия полей и разделитель «—» после известных полей. URL соцсети связывается с извлечённым из него аккаунтом с объяснением. Исходная строка сохраняется в доказательстве. Пустые строки не разрывают единственный явно выделенный профиль, а несколько профилей разграничиваются по заголовкам. Для старых файлов нажмите «Повторить анализ».

## Сохранённые инструменты

- Семья: прямые поля мать/отец, супруги, дети, братья/сёстры и др.; без вывода родства из фамилии или адреса. TXT, CSV, JSON, вложенные family/семья и children. Не подтверждённые и прежние отношения требуют проверки.
- Противоречия и однофамильцы: разные даты рождения, общий контакт в разных источниках, упоминания и отрицания. Это предупреждения, а не доказанные ошибки. Смешанную карточку можно разделить по части источников с предпросмотром и отменой через историю. Семейные и ручные связи остаются для проверки.
- Типы адресов: регистрация, проживание, работа, доставка, прежний адрес. Назначение хранится у каждого фрагмента источника. Совпадение адресов сравнивается по компонентам; существование здания без справочника не подтверждается.
- ГАР/ФИАС: локальный индекс JSON/CSV с полями address, fias_id, необязательно date/source. До 50 000 записей и 20 МБ на проект. Официальная база не включена; портал https://fias.nalog.ru/. Конвертер convert-gar.cjs: `node convert-gar.cjs "папка-региона" "index.json"`. Нужны согласованные AS_ADDR_OBJ, AS_ADM_HIERARCHY, AS_HOUSES и AS_ADDHOUSE_TYPES. Конвертер поддерживает активные актуальные дома с городом и улицей, не всю модель ГАР; квартиры и нестандартные типы не входят. Совпадение удостоверяет только запись в загруженном справочнике, а происхождение пользовательского индекса автоматически не удостоверяется.
- OCR/PDF: локальное распознавание русского/английского, до 30 страниц. Координаты и настоящая уверенность слов/символов, когда движок их предоставил. Выберите найденный узел → «OCR: проверить находку рядом со сканом». Порог подсветки 75% — оценка OCR, не достоверность факта. Старое OCR, исправленный вручную текст и повторяющиеся совпадения могут не иметь точного наложения; повторите OCR для новых данных.
- Фото: EXIF/TIFF, GPS, XMP, IPTC, ICC и другие поддерживаемые теги; сырые блоки JPEG/PNG/WebP, полный JSON и оригинал. Неподдерживаемые фирменные форматы и удалённые теги восстановить нельзя. Даты и координаты могут быть изменены.
- Сравнение расследований: выборочный перенос источников точных совпадений в своём профиле с подтверждением. Копируются файлы целиком, поэтому предварительно проверьте их содержание.

## Ограничения и перенос

Лимиты проекта: 3000 узлов, 15000 связей, 60 файлов, 100 МБ материалов; до 12 МБ на файл. DOCX/XLSX сохраняются как вложения без полноценного извлечения. Локальный анализ основан на правилах и может ошибаться. Совместное упоминание не доказывает владение, родство или истинность факта. Проверяйте важные находки по первоисточнику.

JSON включает все данные проекта. SVG/PDF подготавливают объекты за пределами экрана, сохраняя действующие фильтры. На очень больших проектах анализ, история, шифрование и экспорт могут занимать время. Старый серверный зашифрованный бэкап имеет другой ключ хранилища: для переноса используйте экспорт проекта JSON из прежнего приложения. Исходники этого архива не содержат ключей, пользовательских проектов или тестовых материалов.

## Версия 5.8: значок вкладки

Новая эмблема объявлена сразу в HTML, до запуска приложения. Добавлены SVG, PNG 16/32/48/256, ICO, Apple Touch Icon, manifest и значки 192/512. Адреса иконок имеют параметр версии для обновления кэша. Файлы продублированы в корне и public для обеих точек входа. После публикации закройте старую вкладку и откройте сайт снова. Сначала проверьте содержимое опубликованного public/favicon.svg: новая версия содержит эмблему SG, а не синие квадраты.

## Версия 5.9 — белый вход, тёмное рабочее пространство, новый SG

Страница входа и регистрации возвращена к белому оформлению. Темнее сделан только рабочий экран: однотонные поверхности, без градиентов, размытия и декоративных свечений. Пользовательские фоновые цвета сохраняются; стандартные тёмно-синие фоны переведены в нейтральный чёрный.

Аватар, логотип и все значки заменены на предоставленные белые SG на чёрном фоне. Исходная PNG сохранена без перерисовки.

Выбор цвета больше не перерисовывает граф и не сохраняет историю при каждом движении указателя в системной палитре. Для цвета контура, заливки и фона выберите цвет или введите HEX, затем нажмите «Применить». Массовые изменения по-прежнему имеют отдельное подтверждение. Все прежние режимы графа и анализ сохранены.
