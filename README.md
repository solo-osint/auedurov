# SHADOWGRAPH 6.8

Готовая локальная версия для GitHub Pages. Сервер и вход через ChatGPT не требуются.

## Изменения

- Однотонный чёрный интерфейс: без градиентов у фона, меню, карточек, окон и аватаров. Белая страница входа сохранена. Цвета объектов графа по-прежнему можно менять отдельно.
- Узкая вертикальная панель с иконками, подписями при наведении и фокусе с клавиатуры. Расширенные действия находятся в меню «Все инструменты». Сброс цветов доступен там же.
- Компактные кнопки, поля цвета, инспектор и шапка. Меню проектов и инспектор можно открывать и скрывать. Точки сетки сохранены с помощью SVG, а не CSS-градиента.
- Исправлен расчёт общего плана после переноса панели влево: карточки помещаются в доступную область. Элементы управления 3D остаются на экране.
- На телефоне доска открывается с читаемым приближением к основному объекту. Кнопка «Вписать граф» показывает всю схему. Поддерживаются перемещение пальцем, масштаб двумя пальцами и выдвижной инспектор.
- Инструкция для ПК и телефона содержит актуальные снимки, два местных MP4 с подписями и учебный файл с вымышленными данными. Видео не загружается автоматически.
- Вставка ключа очищает пробелы, переносы и невидимые символы, приводит типографский дефис к обычному. Регистр полезной части ключа сохраняется. Формат шифрования прежних SG1/SGM не изменён.

## Новый профиль владельца auedurov

Рядом с ZIP выдан отдельный файл **SHADOWGRAPH_6.8_ВЛАДЕЛЕЦ.txt**. Он содержит **новый ключ SG1**. Не загружайте этот файл в GitHub, не публикуйте и не передавайте участникам.

После обновления сайта:

1. Откройте обычный экран «Вход» и вставьте новый ключ SG1 из отдельного файла.
2. Первый вход создаст новый локальный профиль **auedurov**. Дополнительная регистрация не нужна.
3. Прежние локальные профили с тем же ником, включая разницу регистра и похожие кириллические символы, будут удалены из списка профилей и рабочего хранилища в **этом браузере**. Другие профили не удаляются.
4. Перед удалением их зашифрованные проекты и настройки записываются в отдельный локальный архив IndexedDB `shadowgraph-retired68`. Новый ключ не расшифровывает этот архив. Для старых данных нужен прежний личный ключ.
5. Ключи удалённых профилей добавляются в локальный список отозванных. Прежний SGO-токен владельца больше не открывает панель в версии 6.8. Обычные ключи других участников продолжают работать.
6. Аватар → «Панель владельца» открывает локальную статистику. Новый SG1 также подходит для повторного подтверждения доступа после истечения 15 минут.

Ник auedurov зарезервирован: обычный профиль не сможет выбрать его при регистрации или переименовании. Если прежняя база открыта в другой вкладке, вход попросит закрыть старые вкладки. Если архивирование не удастся, удаление не начинается. Неподдерживаемые незашифрованные старые данные сохраняются: сначала потребуется их экспорт.

**Эти действия выполняются при первом входе в обновлённую версию в вашем браузере.** ZIP не может заранее удалить данные другого браузера, устройства или старой копии приложения. Отзыв локальных ключей сохраняется в данных браузера; очистка браузера очищает и этот список. Старые версии сайта не получают обновление автоматически.

## Публикация и обновление

Загрузите **содержимое ZIP** в корень репозитория с сохранением всех папок и файла `.nojekyll`. Замените старые файлы, включая `index.html`, `public/workspace.html` и `public/owner-config.json`. Затем откройте GitHub Pages и обновите страницу. Файл с ключом владельца находится отдельно от архива и на сайт не загружается.

Перед обновлением экспортируйте важные проекты. Адрес сайта и браузер должны остаться прежними, иначе локальное хранилище будет другим. Для нового устройства нужны ваш ключ, создание локального профиля с ним и импорт проектов.

Для GitHub Pages настроен относительный путь ресурсов: работают корневой `index.html` и `public/workspace.html`. Все библиотеки, шрифты, изображения, OCR и видеоинструкции находятся внутри архива.

## Возможности, которые сохранены

Главная с проектами, поиск, избранное, архив, создание досок и выбор карточек / кругов / 3D. Анализ загружаемых материалов, правила RU/EN, источники и объяснения связей, семейные и другие явные роли, реквизиты, контакты и события. OCR, метаданные фото, повторный анализ, ручное редактирование, цвет и сброс цветов, авторасстановка, история, поиск пути, сравнение проектов, снимок PNG, JSON и PDF-отчёт.

Автоанализ использует правила и сведения источника. Связь в графе не является независимым подтверждением факта. Сомнительные находки проверяются пользователем.

## Локальность и безопасность

Проекты и настройки профиля защищены AES-GCM, ключ выводится из личного SG1/SGM. В ZIP отсутствуют сами ключи, проекты пользователя и тестовые профили. В `owner-config.json` находятся только проверочные хеши и параметры локального создания владельца. Отладочных способов обхода входа нет.

Статистика владельца относится только к этому браузеру: открытия, создание и импорт, активные вкладки и локальные профили. Это не число всех посетителей сайта. Ключ владельца не расшифровывает другие профили. Административное меню статического приложения не является защищённой серверной ролью: человек, контролирующий браузер и код, может изменить локальный интерфейс и счётчики.

JSON и PDF являются обычными незашифрованными экспортами. Храните их отдельно. Материалы обрабатываются локально; новых внешних сервисов аналитики или загрузки шрифтов не добавлено. Действуют ограничения источников ресурсов и `no-referrer`.

Полную анонимность владельца на GitHub обещать нельзя: сведения аккаунта, адрес репозитория и история коммитов находятся вне приложения.

## Проверка сборки

Проверены создание и повторный вход SG1/SGM, нормализация вставки, новый ключ владельца, резервирование ника, удаление прежнего профиля с зашифрованным архивом, отзыв его ключа и разделение проектов. Проверены общий план, иконки, подсказки, клавиатура, сброс цветов, поиск, 3D, телефонные окна, жесты и инструкция. Мобильная проверка выполнена в Chromium на экранах 320 и 390 пикселей с сенсорными событиями эмулятора; физические устройства отдельно не тестировались.
