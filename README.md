# SHADOWGRAPH 6.7

Локальное приложение для GitHub Pages. Эта сборка продолжает версию 6.6: анализ, источники связей, карточки, круги, 3D, OCR, метаданные, экспорт и PDF сохранены.

## Что нового

- После регистрации и входа открывается главная: поиск, миниатюры проектов, реальные счётчики текущего профиля, избранное, архив и шаблоны представления.
- Окно создания проекта: название, описание и выбор карточек, кругов либо 3D. Можно использовать название по умолчанию. Пустой проект встречает собственный питомец Смотритель.
- Питомец создан специально для SHADOWGRAPH. Оптимизированный прозрачный WebP имеет размер около 38 КБ; отключается в настройках. Анимация учитывает уменьшение движения.
- Настройки: ник, описание, аватар, чёрное / графитовое меню, акцент, русский / английский язык главной и настроек, уведомления, локальная статистика, автоблокировка и хранилище. Нет интеграций, полей API-ключей или списка приложений. Вместо них — правила и конфиденциальность.
- Описание, аватар и настройки шифруются ключом профиля. Ник и дата регистрации остаются в локальном индексе. Ники уникальны в этом браузере; глобального реестра пользователей нет.
- Колесо и кнопки масштаба работают плавно. На телефоне — панорама одним пальцем и масштаб двумя, инспектор в выдвижной панели, прокручиваемая полоса инструментов и адаптированные окна настроек.
- На телефоне / при экономии трафика видео входа заменяется постером. Видеоинструкции не загружаются автоматически. Используются локальные шрифты; Google Fonts больше не запрашиваются.
- В меню «Инструкция» находятся отдельные руководства для ПК и телефона: собственные скриншоты, два коротких MP4 со встроенными подписями и учебный TXT с вымышленными сведениями. Скриншоты можно увеличивать. Инструкция также доступна из меню профиля и инструментов графа.

## Токен и панель владельца

Токен выдан отдельным файлом **SHADOWGRAPH_6.7_OWNER_TOKEN.txt** рядом с ZIP. **Не загружайте этот текстовый файл в GitHub или на сайт.** Внутри ZIP находится только `public/owner-config.json` с проверочным SHA-256, без самого токена.

1. Войдите в свой локальный профиль обычным ключом SG1.
2. Нажмите аватар → «Панель владельца».
3. Введите токен SGO из отдельного файла.

Допуск действует 15 минут в текущей странице и сбрасывается при выходе / перезагрузке. Токен не сохраняется в браузере и не является ключом расшифровки проектов.

Панель показывает **только этот браузер**: число открытий и разных открытых досок, создание / импорт с момента появления журнала, активные профили и вкладки. Онлайн означает видимую активную вкладку с сигналом за последние 45 секунд. Счётчики сохраняются между входами, не содержат материалов и названий проектов, отключаются в настройках; владелец может сбросить их или скачать JSON. История до версии 6.7 не выдумывается.

Это локальное меню, **не серверная административная граница**. Человек, контролирующий браузер и исходный код, может изменить интерфейс или локальные счётчики. Для статистики всех посетителей и защищённых общих ролей потребуется сервер; пользователь выбрал вариант без сервера.

## Конфиденциальность владельца

В файлах сборки проверено отсутствие личного имени, старого адреса размещения и публичных ссылок на аккаунт владельца. У публичных PNG / SVG и значка сайта удалены дополнительные метаданные, а оптимизированный WebP создан без метаданных исходного изображения. Это относится к оформлению сайта, а не к загруженным пользователем материалам: их исходные метаданные сохраняются для анализа. Нет каталога профилей или отдельной публичной страницы владельца. Внешняя загрузка шрифтов удалена, включены `no-referrer` и ограничения источников ресурсов. Никакой новой сетевой аналитики не добавлено.

**Полную невычисляемость обещать нельзя.** GitHub Pages использует аккаунт / репозиторий в адресе; история коммитов и сведения домена могут раскрывать данные вне приложения. GitHub также сохраняет IP-адреса посетителей в целях безопасности. При публикации проверьте настройки приватности GitHub, автора и почту коммитов; смена настроек не удаляет автоматически старые сведения из истории.

Официальные сведения:

- [GitHub Pages и данные хостинга](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)
- [Почта автора коммитов и noreply](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address)

## Обновление и сохранность

Загрузите в свой репозиторий **содержимое ZIP** с сохранением папок, включая `.nojekyll`. Токен владельца в репозиторий не добавляйте. Вход через ChatGPT не требуется.

Локальные данные сохраняются при прежнем адресе сайта и в прежнем браузере. До обновления сделайте экспорт проектов. При смене адреса, браузера или устройства проекты нужно импортировать заново.

Проекты защищены AES-GCM по отдельным ключам профилей. Токен владельца не позволяет открыть чужое хранилище. Автоблокировка требует сохранённого ключа для следующего входа. Восстановления через почту или seed-фразу в этой локальной версии нет.

**Экспорты JSON и PDF — обычные незашифрованные файлы.** Храните их отдельно и проверяйте содержимое перед передачей. Названия, материалы и результаты анализа не переводятся при смене языка меню.

## Проверка

Проверены регистрация → главная, отсутствие лишнего первого проекта, создание и восстановление досок, избранное, шифрование настроек, недоступность проектов другого локального профиля, занятый ник, экранирование названий, проверка токена, отсутствие токена в хранилище / DOM, отсутствие внешних HTTP-запросов приложения, адаптивные окна и плавный масштаб. Импорт старого проекта, два повторных анализа, PDF, локальный OCR и масштаб 3D также проверены. Мобильный режим проверен в Chromium на узком экране и с настоящими сенсорными событиями эмулятора. Физические устройства iOS / Android отдельно не тестировались.

# SHADOWGRAPH 6.0 — GitHub Pages

Готовый статический сайт с интро, локальными зашифрованными профилями и графом расследования. Серверная часть и вход через ChatGPT не используются.

## Установка

1. Перед обновлением сохраните резервный экспорт своих проектов.
2. Распакуйте архив. Загрузите его содержимое в корень репозитория, сохраняя папку public.
3. В Settings → Pages выберите Deploy from a branch, main, /(root).
4. Откройте сайт по HTTPS. При обновлении используйте прежний адрес: локальные данные привязаны к адресу сайта и браузеру.

Регистрация создаёт локальный профиль и случайный ключ. Можно указать ранее выданный ключ SG1/SGM. Сохраните ключ отдельно: без него проекты не восстановить. После перезагрузки страницы нужно войти по ключу заново. Метаданные профилей и занятость ников отдельные в каждом браузере/на устройстве; централизованных аккаунтов, глобальных ролей и входа через Google/Telegram/GitHub нет. Материалы не отправляются на сервер приложения. Экспортированные JSON, PDF и метаданные фото не зашифрованы.

## Новое в этой версии

- Завершено исправление больших графов: рабочий масштаб вместо тысячи микрокарточек, чистый общий план без веера связей файлов, локальные маршруты в фоне. «Общий план» показывает всё; приблизьте область для работы. «Линии: читаемый вид» позволяет явно включить все линии. Позиции, объекты и связи не удаляются. На плотных участках часть маршрутов может оставаться упрощённой.
- «Вид: карточки / Вид: круги» переключает обычные блоки и сетевой граф с круглыми узлами. Положение кругов хранится отдельно. Работают выбор, перемещение, поиск Enter, фильтры, связи, статусы и объяснения. В сетевом виде «Авторасстановка» пересчитывает круги в отдельном потоке. На большом отдалении подписи и линии упрощаются. Сеть одновременно рисует до 2000 линий, карточки — до 2500 в режиме всех линий; данные остаются полными.
- Интерфейс стал темнее. Выбранный пользователем фон проекта сохранён. В инспекторе доступны цвет заливки отдельного блока, палитра и изменение заливки всех блоков. Цвет контура и цвет связей редактируются отдельно.
- Новая эмблема установлена в интерфейс и favicon. «Инструменты → Аватар SHADOWGRAPH» скачивает PNG/SVG. Файлы доступны также в public/brand.
- PDF получил тёмную обложку, обзор статусов, отдельную страницу графа, реестр источников S, карточки объектов N и связи R с объяснениями. Изображение учитывает режим и фильтры; реестры содержат весь проект. Большая схема на печатной странице будет мелкой — для деталей используйте интерактивный проект.
- Анализ понимает дополнительные названия полей и разделитель «—» после известных полей. URL соцсети связывается с извлечённым из него аккаунтом с объяснением. Исходная строка сохраняется в доказательстве. Пустые строки не разрывают единственный явно выделенный профиль, а несколько профилей разграничиваются по заголовкам. Для старых файлов нажмите «Повторить анализ».

## Сохранённые инструменты

- Семья: прямые поля мать/отец, супруги, дети, братья/сёстры и др.; без вывода родства из фамилии или адреса. TXT, CSV, JSON, вложенные family/семья и children. Не подтверждённые и прежние отношения требуют проверки.
- Противоречия и однофамильцы: разные даты рождения, общий контакт в разных источниках, упоминания и отрицания. Это предупреждения, а не доказанные ошибки. Смешанную карточку можно разделить по части источников с предпросмотром и отменой через историю. Семейные и ручные связи остаются для проверки.
- Типы адресов: регистрация, проживание, работа, доставка, прежний адрес. Назначение хранится у каждого фрагмента источника. Совпадение адресов сравнивается по компонентам; существование здания без справочника не подтверждается.
- ГАР/ФИАС: локальный индекс JSON/CSV с полями address, fias_id, необязательно date/source. До 50 000 записей и 20 МБ на проект. Официальная база не включена; портал https://fias.nalog.ru/. Конвертер convert-gar.cjs: `node convert-gar.cjs "папка-региона" "index.json"`. Нужны согласованные AS_ADDR_OBJ, AS_ADM_HIERARCHY, AS_HOUSES и AS_ADDHOUSE_TYPES. Конвертер поддерживает активные актуальные дома с городом и улицей, не всю модель ГАР; квартиры и нестандартные типы не входят. Совпадение удостоверяет только запись в загруженном справочнике, а происхождение пользовательского индекса автоматически не удостоверяется.
- OCR/PDF: локальное распознавание русского/английского, до 30 страниц. Координаты и настоящая уверенность слов/символов, когда движок их предоставил. Выберите найденный узел → «OCR: проверить находку рядом со сканом». Порог подсветки 75% — оценка OCR, не достоверность факта. Старое OCR, исправленный вручную текст и повторяющиеся совпадения могут не иметь точного наложения; повторите OCR для новых данных.
- Фото: EXIF/TIFF, GPS, XMP, IPTC, ICC и другие поддерживаемые теги; сырые блоки JPEG/PNG/WebP, полный JSON и оригинал. Неподдерживаемые фирменные форматы и удалённые теги восстановить нельзя. Даты и координаты могут быть изменены.
- Сравнение расследований: выборочный перенос источников точных совпадений в своём профиле с подтверждением. Копируются файлы целиком, поэтому предварительно проверьте их содержание.

## Ограничения и перенос

Лимиты проекта: 3000 узлов, 15000 связей, 60 файлов, 100 МБ материалов; до 12 МБ на файл. DOCX/XLSX сохраняются как вложения без полноценного извлечения. Локальный анализ основан на правилах и может ошибаться. Совместное упоминание не доказывает владение, родство или истинность факта. Проверяйте важные находки по первоисточнику.

JSON включает все данные проекта. SVG/PDF подготавливают объекты за пределами экрана, сохраняя действующие фильтры. На очень больших проектах анализ, история, шифрование и экспорт могут занимать время. Старый серверный зашифрованный бэкап имеет другой ключ хранилища: для переноса используйте экспорт проекта JSON из прежнего приложения. Исходники этого архива не содержат ключей, пользовательских проектов или тестовых материалов.

Все прежние режимы графа и анализ сохранены.


## Версия 6.0 — структура досье и финансы

Анализ распознаёт Markdown-поля **ФИО:**, разделы досье, заголовки родственников и русские даты вида «14 марта 1996 года». После раздела семьи последующие основные разделы относятся к главному человеку, а сведения внутри родственника — к нему. Заголовок досье с другим порядком ФИО не создаёт отдельного человека. Девичья фамилия в скобках сохраняется в вариантах имени. Связи родства имеют объяснение и требуют проверки.

Новые финансовые типы: доход, расходы, сбережения, обязательства, бюджет. Хранятся сумма/диапазон, валюта, период, приблизительность, указание налогов и исторический интервал. Неизвестные валюта и период не додумываются. Доходы из таблицы карьеры привязаны к периоду и должности; они не считаются текущим доходом. Годовые суммы, семейные итоги и реальные финансовые возможности не вычисляются автоматически. Финансовые поля поддерживаются также в TXT, CSV и JSON, включая salary/income/expense/savings/debt.

Адрес, вуз, питомцы и автомобиль могут собираться из отдельных полей соответствующего раздела. Дополнительные атрибуты доступны в инспекторе человека. Последняя оборванная строка не дополняется вымышленными данными.

Для уже загруженного документа нажмите «Повторить анализ». Точные дубли ФИО с разным порядком слов в том же файле объединяются только если это единственный явно указанный человек с таким полным именем в документе; источники и изменения сохраняются через историю. Однофамильцы между разными файлами автоматически не объединяются. Прежние ручные/ошибочные находки могут потребовать проверки.


## Версия 6.1 — идентификаторы, события и происхождение файлов

Новые типы: ИНН, ОГРН/ОГРНИП; IBAN, БИК, р/с, маска карты, криптоадрес; VIN, госномер, СТС/ПТС; кадастровый номер и индекс; IPv6 и CIDR; Message-ID и хопы Received; IMEI, MAC, серийный номер, SHA-256; событие; контактная ссылка мессенджера. Поддержка основана на явных полях и ограниченном наборе форматов, не на поиске сведений о человеке в интернете.

- Контрольные цифры ИНН/ОГРН, mod-97 IBAN и Luhn IMEI используются как локальные признаки качества. Невалидный номер сохраняется для проверки. Это не проверка реестра, существования счёта, подлинности документа или владельца. IBAN проверяется по общей форме и mod-97, без полной национальной таблицы длины.
- Реквизит связывается с организацией, автомобилем или суммой только при однозначном близком контексте записи. Если контекст неясен, остаётся связь с файлом и предупреждение. Соседство с суммой не доказывает отправителя/получателя платежа.
- Подписанные номера карт маскируются в анализе, доказательствах и ключах графа; последние четыре цифры не считаются уникальным идентификатором и не подтверждают владельца. Сам исходный файл сохраняется как загружен и может содержать полный номер. Перед экспортом исходников проверьте их содержимое. Произвольные неподписанные числа за карты не принимаются.
- VIN проверяется по 17 символам без I/O/Q; госномер — по поддерживаемой российской форме A123BC77/А123ВС77. СТС/ПТС извлекаются только из подписанных полей; проверка госреестров не производится.
- Карты: явные ll/pt Яндекса и m/map 2ГИС читаются как долгота,широта; Google /maps/@ — как широта,долгота. Дополнительно поддержан OpenStreetMap mlat/mlon. Точка/центр карты не подтверждает присутствие человека. Короткие ссылки не раскрываются запросами наружу; прочие варианты URL могут не распознаваться.
- EML: From, Reply-To, To, Message-ID, свёрнутые Received. Хопы идут от нижнего Received к верхнему. Заголовки могут быть подделаны и не устанавливают отправителя. Разбираются доступные обычные адреса в заголовках; это не полная реализация всех кодировок MIME/EML.
- WhatsApp wa.me, Viber viber://chat?number, Signal signal.me, MAX max.ru. Непрозрачные ссылки Signal/MAX сохраняются как ссылки/приглашения; ник или номер из случайного токена не выдумывается. Наличие аккаунта не проверяется.
- События: договор, встреча, увольнение, приём на работу, свадьба, переезд, знакомство с явной датой; поддержаны ISO, DD.MM.YYYY и русские месяцы. «Уволен в 2019» сохраняет только год, без добавления дня и месяца. «Инструменты → События и даты» открывает источники.
- Фотографии с включённым анализом индексируют поддерживаемые GPS и серийные номера EXIF автоматически. Просмотр метаданных также может добавить их в граф. EXIF можно изменить; координаты не подтверждают местонахождение владельца. Неподдерживаемые или удалённые теги не восстанавливаются.
- SHA-256 вычисляется по исходным байтам файла. Совпадение связывает файлы как одинаковое содержимое; файлы не удаляются и не считаются независимыми подтверждениями. Для старых материалов есть «Инструменты → Одинаковые файлы / SHA-256». Проекты и вложения остаются локальными и зашифрованными.
- Коллега, сосед/соседка, однокурсник/однокурсница, рекомендатель: явные поля создают подписанную связь. Совпадение работы/адреса само по себе не создаёт такую роль.

Дополнительно: «Проверка идентификаторов» собирает предупреждения контрольных цифр/формы и расхождения идентификаторов в одной карточке организации или машины. Это повод сравнить источники и одноимённые объекты, а не автоматически выбрать «истинное» значение.

Формальные ссылки: https://www.rfc-editor.org/rfc/rfc5322 и https://www.swift.com/standards/standards-resources . Реестры, банки, мессенджеры, криптосети и государственные сервисы не опрашиваются. Для старых текстовых файлов используйте «Повторить анализ», для фотографий — просмотр метаданных/новую загрузку с включённым анализом. Перед обновлением сохраните резервный экспорт.

## Версия 6.2 — расширенные правила и безопасный контекст

Добавлены 67 правил подписанных полей и отдельные распознаватели форматов. Сохраняются разные пространства имён для документов, организаций, геокодов, контактов и технических идентификаторов. Значение `12345678` без подписи не превращается во все возможные номера сразу. Документы, маски карт и свойства записей разделены по источнику/записи; одинаковый номер сам по себе не объединяет людей. Код классификатора может встречаться у нескольких организаций и не считается уникальным идентификатором компании.

Статья кодекса сохраняется только как свойство найденного дела. Нет дела — есть предупреждение, а не вывод об обвинении человека.
- Смерть с явной датой и подписанное место захоронения. Невозможная дата, например 31.02.2024, не превращается в событие.
- Адреса и география: а/я, подъезд/домофон/код, geohash, MGRS/UTM, what3words, Place ID/CID/OSM node/way/relation/Yandex Org ID, высота/точность возле найденной точки, коды страны/региона. MGRS/UTM сохраняются в исходной системе; datum не предполагается, пересчёт не выполняется. What3words и ID карт не разрешаются во внешние сервисы. Неподписанный geohash должен содержать и буквы, и цифры, чтобы обычное слово не стало геокодом.
- Транспорт: подписанные аэропорт/вокзал/станция/IATA/ICAO, километр трассы, рейс с маршрутом/датой в исходной записи, поезд/вагон/место, PNR, отель и номер брони/даты заезда и выезда, подписанные трек-номера Почты России/СДЭК/UPS/DHL (плюс узнаваемая форма UPS), IMO/MMSI/борт/позывной, контейнер. Наличие билета или фактическая поездка не подтверждаются.
- Свойства: год выпуска/пробег/топливо/двигатель автомобиля; чип/порода животного; годы учёбы/факультет; период приёма/увольнения у работы. Нужен однозначный соответствующий объект в записи.
- Языки и подписанные группа крови/аллергии/вероисповедание/партия/членство. Такие сведения не выводятся из фамилии, фотографий, окружения или свободных предположений; медицинских заключений нет.
- Контакты: Skype, ICQ, Jabber, Matrix, IRC; ссылки Snapchat, Pinterest, Medium, Substack, Boosty, Дзен, Rutube, Kick, Patreon, WeChat, Line, KakaoTalk. Их можно выбирать вручную в поле соцсети. Telegram/Discord-приглашения — отдельный тип без предположения о составе участников. `t.me/s/channel` — канал, не человек.
- PayPal/ЮMoney/QIWI/Boosty-ссылки, подписанный кошелёк; tel/SIP, факс/добавочный. Номер из tel использует обычный телефонный узел. Плюс-адрес почты получает связанный вариант записи без суффикса; этот вариант не считается найденным отдельным ящиком и не объединяет людей.
- IDN/punycode приводятся к одному домену. Onion — отдельный тип без открытия; magnet/infohash, ENS без разрешения в кошелёк; GitHub-репозиторий/коммит, npm/PyPI без установки; DNS NS/MX и WHOIS-регистратор/даты только из загруженного текста; ASN и хост:порт.
- Каноническая ссылка удаляет только `utm_*`, `fbclid`, `yclid` и связана с исходной. Регистр пути URL сохраняется. Bit.ly/t.co/clck.ru отмечаются нераскрытыми. Для основных платформ и коротких ссылок поддержан адрес без `https://`.
- Хештег у канала/записи; цитата с явным именем говорящего связывается только при однозначном совпадении с человеком того же абзаца. Windows/Linux/UNC-пути не открываются. Имена файлов из подписанного списка содержимого архива становятся отдельными узлами; содержимое ZIP автоматически не распаковывается.
- ISO-время сохраняет исходное смещение. У источника показан язык извлечённого фрагмента по алфавитам: русский/английский/смешанный; это простая пометка, без перевода и определения языка по смыслу.

### Как использовать

1. При загрузке включите галку «Анализ». Новые правила работают с TXT/MD/извлечённым текстом и подписанными полями JSON, CSV/TSV, JSONL/NDJSON. Обработка HTML использует извлечённый текст и доступные структурированные данные. Для изображений/сканов применяйте OCR, затем проверьте распознанный текст. Возможности чтения контейнеров документов не расширены этой версией.
2. Пишите одно поле на строку, например `ОКВЭД: 62.01`, `Виза: V12345`, `Срок действия: 12.03.2027`. В JSON/CSV используйте такие же имена полей. Набор поддерживаемых подписей и форматов ограничен правилами, это не универсальное понимание любого произвольного текста.
3. Выберите узел или нажмите `?`: доступны правило, файл, строка/путь, причина связи и свойства с исходными фрагментами. Чувствительные поля помечены как явные сведения источника.
4. «Инструменты → Контекст новых находок» показывает значения, для которых объект связи неоднозначен. Они остаются у источника; случайный владелец не назначается. «Проверка идентификаторов» и «События и даты» дополняют проверку.
5. Для старых текстовых материалов нажмите «Повторить анализ». Старые ручные узлы не удаляются; устаревшие находки могут потребовать проверки в истории/инспекторе. Проверяйте OCR и источники перед подтверждением.

Ограничения проекта сохранены: до 500 находок на один анализ файла, 3000 узлов, 15000 связей и 60 материалов на расследование, исходный файл до 12 МБ. При достижении лимита нужно разделить материалы. Формат/контрольная цифра не доказывают регистрацию, подлинность, владение или существование объекта. Короткие ссылки, внешние реестры, DNS, WHOIS, мессенджеры и блокчейны автоматически не опрашиваются.

Рабочее пространство остаётся плоским тёмным, вход белым, эмблема — предоставленная SG. Развёртывание: содержимое ZIP загрузить в папку, из которой публикуется GitHub Pages. Сервер, ChatGPT и облачная учётная запись не требуются. Профили локальные, проекты зашифрованы по личному ключу. Исходники документов сохраняются как загружены; маскирование номера карты в графе не редактирует сам оригинальный файл.

## Версия 6.3 — связи в обычных текстовых досье

Исправлена потеря контекста у файлов с обычными заголовками, например `ЛИЧНОСТЬ, КОНТАКТЫ И АККАУНТЫ`, вместо Markdown `##`, и подписью `Полное ФИО:` вместо точного `ФИО:`. Добавлена поддержка некоторых уточнённых подписей: учебный/дополнительный телефон, доход с именем, адрес с датой, учебный VIN/БИК/IBAN и другие поддерживаемые реквизиты. Исходная строка, включая предупреждения и оговорки, сохраняется в объяснении.

- Разделы одного явно названного профиля связываются с этим человеком. Обычный текстовый режим включается при наличии явного ФИО и как минимум двух заголовков заглавными буквами; это не произвольное понимание любого повествования. Строки идентификаторов с цифрами не принимаются за заголовки. При нескольких одинаковых явных ФИО данный режим не объединяет их автоматически.
- Строки `Отец: полное имя, дата…`, `Младший брат: …`, `Сосед по этажу: …`, `Рекомендатель на работу: …` и поддерживаемые другие роли разбираются отдельно. Дата родственника относится к нему, а не к основному человеку.
- Реквизиты организации привязываются к её блоку. Учредитель и бенефициар связываются с названной организацией; основной человек не становится учредителем по соседству текста. Один человек может иметь обе явно указанные роли — отдельные подписанные связи сохраняются.
- Несколько подписанных VIN/госномера/СТС/ПТС на одной строке разбираются по отдельности. Удалены некоторые дубли ссылок и никнеймов из-за точки в конце предложения. Плановый ежемесячный платёж не превращает весь остаток кредита в ежемесячную сумму.
- Технические разделы, неатрибутированные примеры и явные оговорки о чужом документе/не личном счёте не создают автоматического владения у основного человека. Такие находки могут оставаться связанными только с исходным файлом. Кнопка «Линии файлов» показывает эти связи.
- У новых связей есть исходная строка, раздел и причина в карточке/кнопке `?`. Сохраняется статус утверждения источника; найденная связь не считается подтверждённым фактом.

Исправленные связи добавляются, поддерживаемые старые автоматические привязки обновляются; ручные узлы, связи и подтверждённые правки сохраняются. Старые неподходящие находки не удаляются массово: после обновления часть прежних узлов может потребовать ручной проверки. Для чистого результата можно загрузить оригинал в новое расследование.

### Защита от смешения

- Разные люди в соседних записях, даже с одинаковым первым именем, остаются разными. Части имени не собираются через границу следующего профиля или строки таблицы.
- Разные значения одноимённых полей сохраняются отдельно с предупреждением, а не затирают друг друга. Если в одной записи указаны разные полные имена, автоматическая принадлежность общих атрибутов не выбирается.
- Неизвестное поле `Number / Номер` не превращается автоматически в телефон, паспорт или счёт. Исправляются перечисленные опечатки; произвольное приблизительное угадывание названия поля не применяется.
- Неоднозначный английский `DOB: 09/12/1983` остаётся исходной строкой с пометкой «сомнительно», без выбора DD/MM против MM/DD. Явный ISO-формат или однозначный числовой порядок разбираются отдельно.
- Исходные подписи, строки/колонки/пути JSON и причина связи доступны через `?`. Подписанные номера карт маскируются в графе и извлечённом текстовом кэше, включая новые английские подписи и массивы. Одинаковые последние четыре цифры не объединяют разные карточные поля. Сам исходный файл сохраняется как загружен и может содержать полный номер; маскирование графа не редактирует оригинал.

Внутри приложения установлены чёрный холст, почти чёрные панели и нейтральные активные кнопки; декоративные градиенты и фиолетовая заливка навигации убраны. Страница входа остаётся белой. Индивидуальные цвета узлов/связей, выбор фона и применение цвета отдельной кнопкой сохранены.

Для сохранённых материалов обновите сайт и нажмите «Повторить анализ». Сначала сохраните резервный экспорт. Старые ручные узлы не удаляются массово; отдельные прежние находки могут потребовать проверки. Поддержка языков относится к русским и английским подписям из словаря, а не ко всем существующим языкам и формулировкам.

Проверки: все 1131 варианта словаря; сборка частей имени и известные опечатки; текст/JSON/CSV, повторные подписи, одноимённые части у разных людей, источники и маскирование; английские родственники и именованные телефоны; неоднозначные даты; ранее предоставленное досье; EXIF/SHA-256/EML; два повторных анализа без роста дублей; вход по ключу после перезагрузки. В браузере проверены чёрные поверхности без градиентов, белый вход и сохранённая смена цвета блоков без перерисовки при движении выбора цвета. Проверочные примеры — вымышленные; пользовательские материалы и ключи в дистрибутив не входят.

## Версия 6.5 — карта и управление

- Кнопка «Карточки ▾» открывает выбор: карточки, круги, вращаемая 3D-сеть. Объекты в 3D имеют координаты X/Y/Z и перспективную проекцию; сцена рисуется локально, без внешних библиотек или сервера.
- 3D: перетаскивание мышью вращает сцену, Shift + перетаскивание сдвигает, колесо меняет масштаб. Стрелки вращают, 0 возвращает вид спереди, F вписывает граф. «Спереди» и «Вписать» доступны на панели сети. Ракурс сохраняется в зашифрованном проекте.
- Круги: перетаскивайте сами узлы или свободное пространство. В обоих режимах щелчок выбирает объект; двойной щелчок открывает объяснение / метаданные. Наведение показывает полное имя. В приоритете подписи людей и выбранных объектов; остальные подписи показываются по доступному месту, чтобы не перекрывать друг друга. Непоказанную подпись можно увидеть наведением или через поиск.
- Файлы и хеши не определяют смысловой центр сети. «Инструменты → Линии файлов» включает исходные материалы в круговых представлениях. Скрытие меняет отображение, а не удаляет источник или связь.
- Авторасстановка карточек: группировка по людям и связям либо по файлам, рамки групп по желанию. Расстановка выполняется отдельно от интерфейса, закреплённые карточки сохраняют позиции. Старый проект можно обновить кнопкой авторасстановки.
- Маршруты огибают карточки, используют короткие каналы и отдельные точки входа. На пересечениях добавляется разрыв линии вместо прежней дуги. Разрыв не означает обрыв связи. Произвольный сложный граф может иметь пересечения; наведение на линию выделяет её отдельно.
- «Сброс цветов» возвращает цвета типов объектов, тёмные заливки и нейтральные связи. Можно сбросить весь проект или выбранный узел / связь; отдельно выбрать контуры, заливки и связи. Данные, позиции, толщины, пунктир и статусы сохраняются. Сброс доступен в истории изменений.
- «Снимок» скачивает PNG текущего вида или всего графа карточек. Можно добавить название и дату. Для 3D сохраняется текущий ракурс. SVG карточек остаётся векторным; SVG кругов / 3D содержит снимок сцены PNG.
- «Панели» справа внизу скрывает и возвращает шапку, расследования, инспектор, инструменты, подсказки / масштаб и строку состояния. Эта кнопка остаётся видимой, даже если скрыть всё. Есть «Показать всё» и отдельные кнопки сворачивания. Состояние панелей запоминается в браузере.
- Разделы бокового меню и инспектора сворачиваются. Диалоги можно свернуть кнопкой «−», затем развернуть плавающую карточку. Панель сети также можно свернуть.
- Расширенные команды перенесены в «Инструменты», чтобы панель графа занимала меньше места. Загрузчик справочника и другие видимые поля загрузки имеют оформленную кнопку и название выбранного файла.
- Исправлены служебные заглушки в подписях возраста, породы и года автомобиля. Остальные правила анализа версии 6.4 сохранены.

Проверено в Chromium: три представления, вращение, сохранение ракурса и локального зашифрованного проекта, импорт TXT / JSON / EML / фото, повторный анализ, сброс цветов, PNG, сворачивание и восстановление панелей. У проекта остаётся белый экран входа и однотонное чёрное рабочее пространство. Новых сетевых запросов анализ не делает.

## Версия 6.6 — аккуратные связи и PDF-досье

- Убраны плашки «GRAPH ENGINE READY» и «LOCAL / PRIVATE». Панель графа занимает одну общую область без отдельного служебного блока справа. Сворачивание инструментов доступно через «Панели».
- Расстановка карточек теперь помещает человека в центр своей группы. Связанные сведения распределяются по обе стороны; небольшие ветви сохраняются рядом. Между колонками и рядами оставлены свободные каналы для линий.
- Маршруты сортируются от коротких к длинным; повороты получают больший штраф. Прямые участки, одинаковые скругления и симметричные смещения параллельных линий уменьшают обходы и лишние изгибы. Пересечение остаётся разрывом одной линии, а не точкой соединения.
- На проверочном примере с 49 объектами все 54 смысловые связи получили маршруты, без прохождения через карточки. Суммарная длина маршрутов уменьшилась примерно на 42%, число изгибов — примерно на 18% относительно версии 6.5. Это результат конкретного примера, а не обещание для любого графа.
- Чтобы обновить расположение существующего проекта, нажмите «Авторасстановка → По людям и связям → Расставить». Цвета и закреплённые карточки сохраняются. Представления «Круги» и «3D-сеть» остаются доступны.

### Новый PDF-отчёт

- Строгая чёрная обложка, единая сетка полей, встроенные кириллические шрифты, номера страниц и названия разделов.

- Изображения карты отражают выбранный вид и фильтры. Реестры содержат все объекты и связи. Для 3D используется текущий ракурс.
